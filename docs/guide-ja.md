# かえりみち 使い方ガイド（自治体の交通担当の方・ケアマネジャーの方へ）

かえりみち（Kaerimichi）: https://munimv2.github.io/kaerimichi/

「バスで病院へ行って、その日のうちに帰ってこられるか」を、公開されている時刻表データ（GTFS）から調べる無料のウェブアプリです。
登録・インストールは不要で、データはすべてお使いのブラウザの中で処理されます（サーバーへの送信はありません）。

このガイドでは、よくある3つの使い方を手順で説明します。

- A. 住民の方の通院・買い物の往復を調べて、メモにして渡す（ケアマネジャー・地域包括支援センター・ご家族）
- B. 町全体で「日帰りで往復できない停留所」を洗い出す（自治体の交通担当・地域公共交通会議）
- C. デマンド交通（予約制）でどこまで補えているかを見る（デマンド交通を導入している町）

---

## はじめに: 路線データと日付を選ぶ

1. 「1. 路線データ」で都道府県を選び、町や事業者のバスを選びます。GTFSデータリポジトリ（https://gtfs-data.jp/ ）で公開されている全国約600のデータから選べます。
2. 停留所が地図に表示されるまで待ちます（大きなデータでは数十秒かかることがあります）。
3. 日付を確認します。平日と土日でダイヤが違う町が多いので、通院する曜日に合わせてください。

一覧にない町でも、手元にGTFSのzipファイルがあれば読み込めます。

## A. 一人の方の往復を調べる（ケアマネジャー・ご家族向け）

1. 「3. 出発」に自宅の最寄りの停留所名を入力するか、地図の停留所をクリックして「ここから出発」を押します。
2. 「4. 行き先」で「病院」「駅」「役場」「買い物」のボタンを押すと、停留所名からその町の病院などの停留所が選ばれます。押すたびに次の候補に切り替わります。目的の停留所がなければ、名前を入力するか地図から選んでください。
3. 「目的地での最低滞在」を、診察や買い物に必要な時間に合わせます（例: 通院なら60〜120分）。
4. 結果に、その日に往復できるか、行き先に最も早く着く時刻、帰りの最終便、最大の滞在時間、帰ってこられる最後の行きの便が表示されます。乗り換え1回までの経路も探します。
5. 結果の下のボタンで、往復の可否と便の一覧を「往復メモ」として印刷・PDF保存したり、LINEやメールに貼れる文章としてコピーしたりできます。

注意: 時刻表データにもとづく目安です。遅れ・運休・臨時ダイヤ、停留所までの歩行、乗降の介助は考慮していません。お出かけの前に、事業者や町の最新の時刻表もご確認ください。

## B. 町全体の「日帰りで往復できない停留所」を洗い出す（自治体向け）

1. 「4. 行き先」で、病院・駅・役場など、町の生活の拠点になる停留所を選びます。
2. 地図の上の「地図の色」で「行き先へ日帰りで往復できるか（交通空白マップ）」を選びます。
3. すべての停留所が、その行き先へ日帰りで往復できるかで色分けされます。
   - 往復できる（直通）／往復できる（乗り換えあり）
   - 行けるが帰りに間に合わない、帰りの便がない、行き先へ行けない
   - この日は発車がない
   凡例に区分ごとの停留所の数が表示され、同じ週の平日・土曜・日曜の数も並びます。曜日をクリックすると、その日に切り替わります。
4. 停留所をクリックすると、その停留所からの到着時刻・帰りの最終・最大滞在が表示されます。
5. 資料づくりには次の機能が使えます。
   - 「CSVでダウンロード（停留所ごとの判定）」: 停留所ごとの判定をExcelなどで集計できます。
   - 集計のコピーと、地図と集計の印刷: 地域公共交通会議などの資料に貼り付けられます。
6. 「目的地での最低滞在」を変えると、通院（長め）と買い物（短め）で、往復できる範囲がどう変わるかを比べられます。

使い方の例:
- ダイヤ改正の前後で、病院へ日帰りで往復できる停留所の数がどう変わるかを比べる（改正後のGTFSを読み込んで同じ行き先・同じ曜日で比較）。
- 平日は往復できるが土日は往復できない地区を見つける。
- 「交通空白」の検討で、停留所単位の根拠として使う。

判定は時刻表データだけにもとづく目安です。「交通空白」の公式な判断は、各自治体と地方運輸局が行うものです。

## C. デマンド交通（予約制）でどこまで補えているかを見る

1. 「5. デマンド交通（予約制）を重ねる（任意）」で、町のデマンド交通を選びます。公共交通オープンデータセンターが公開した、14自治体・16件のデマンド交通データ（GTFS-Flex形式）を用意しています。その町の路線バスのデータがGTFSデータリポジトリにあれば、一緒に読み込まれます。
2. 地図に、デマンド交通の運行区域（青い破線）や乗降ポイント（小さな青い点）が重なります。
3. 交通空白マップでは、「バスでは往復できないが、デマンド交通（予約制）なら往復できる見込み」の停留所が青で表示され、凡例にその数が出ます。
4. 青い停留所をクリックすると、デマンド交通の運行時間と予約方法（何分前まで・電話番号など、データにある場合）が表示されます。
5. 「重ねない」に戻すと、バスだけの判定に戻ります。重ねる前と後の数の違いが、デマンド交通で埋まった交通空白の目安になります。

デマンド交通の判定は、区域・運行時間・予約ルールのデータにもとづく「見込み」です。実際に予約が取れるか、何分かかるかは、運行事業者にご確認ください。

## データと出典

- 路線バス: GTFSデータリポジトリ（https://gtfs-data.jp/ ）の各データ。各データの提供者とライセンス（CC BY 4.0 など）に従って出典を表示しています。
- デマンド交通: 公共交通オープンデータセンター（https://www.odpt.org/ ）が公開したGTFS-Flexデータ（CC BY 4.0）。多くは公共交通オープンデータチャレンジ2026の期間中の公開です。
- 地図: 地理院タイル（国土地理院）
